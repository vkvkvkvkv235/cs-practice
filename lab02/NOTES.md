Рабочая папка (working directory) — директория с файлами, которые вы редактируете. Здесь изменения ещё не отслеживаются Git.



Индекс (staging area / index) — промежуточная область, куда попадают изменения после git add. Это то, что войдёт в следующий коммит.



Коммит (commit) — зафиксированный снимок состояния индекса с уникальным хешем, автором, датой и сообщением. Хранится в истории репозитория.



\*\*Git\*\* — распределённая система контроля версий, работает локально.

\*\*GitHub\*\* — облачный сервис для хранения Git-репозиториев и совместной работы.





\## Использованные команды



\- `git status` — показывает состояние рабочей папки и индекса.

\- `git diff` — сравнивает рабочую папку с индексом.

\- `git diff --staged` — сравнивает индекс с последним коммитом.
